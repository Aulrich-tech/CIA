Module 7: Web Application Attacks

Web Server Attack: A web server is a computer system that stores, processes, and delivers web pages to clients via HTTP.

Web server components

Document Root
Stores critical HTML files related to the web pages of a domain.
Server Root
Stores server configuration.
Virtual Document Tree
Storage on different machines or disks.
Web Proxy
Located between the web client and web server to pass all the requests.
Virtual Hosting
Multiple domains can be placed on the same server.

Common web server attacks

DNS Server Hijacking
Compromises the DNS server and changes the DNS settings.
DNS Amplified Attack
Takes advantage of the DNS method to perform amplified attacks. Uses compromised PCs with spoofed IP addresses.
Directory Traversal Attack
Attackers use the ../ sequence to access restricted directories. Trial-and-error method to navigate outside.
Website Defacement
An attacker makes unauthorized changes to a website's content, resulting in changes to the visual appearance of the web page or website.
Dictionary Attack
Using a predefined file with an automated password cracking program.
Server Misconfiguration
Configuration weakness in web infrastructure that can be exploited.
HTTP Response-Splitting Attack
Adding header response data into the input field.
Web Cache Poisoning Attack
Likely to be performed by the attacker if the web server and application have HTTP response-splitting flaws.
SSH Brute Force Attack
Create an encrypted SSH tunnel to gain unauthorized access and transmit malware.
Web Server Password Cracking
Hack using the most common passwords. Manually guess passwords or perform dictionary, brute-force, or hybrid attacks.
Server-Side Request Forgery (SSRF)
Send a crafted request to internal or back-end servers.
Hybrid Attack
Employing more than one attack.
Web Server Attack Tools
Support fully automated exploitation of web servers.

Web applications

Web Applications
Provide an interface between end users and web servers. Enforce certain security policies.
Web Service
An app or software deployed over the internet that uses standard messaging protocols to enable communication between applications for different platforms.

Vulnerability stack

Layer 7: Custom Web Application
Evading alarms when entering malicious traffic.
Layer 6: Third-Party Components
Exploiting vulnerabilities in third-party components.
Layer 5: Web Server
Exploiting vulnerabilities in the web server.
Layer 4: Database
Exploit the target database server.
Layer 3: Operating System
Exploiting vulnerabilities in the target operating system.
Layer 2: Network
Flood the switches with requests that exhaust the CAM table.
Layer 1: Security
Exploiting weaknesses in the security layer.

OWASP Top 10

A1 Injection Flaws
Occurs when untrusted data is sent to an interpreter as part of a command or query.
  • SQL Injection: injecting malicious SQL queries.
  • Common Injection: injection of malicious code.
  • LDAP Injection: injection of LDAP statements.
A2 Broken Authentication
Occurs when a sniffer captures the cookie that contains the session ID.
A3 Sensitive Data Exposure
Occurs when an application uses poorly written encryption code.
A4 XML External Entity (XXE)
Occurs when a misconfigured XML allows an application to parse XML input from an unreliable source.
A5 Broken Access Control
Occurs when attackers identify a flaw related to access control and bypass authentication.
A6 Security Misconfiguration
Unvalidated inputs, parameters/form tampering, improper error handling, or insufficient transport layer protection.
A7 Cross-Site Scripting (XSS)
Occurs when an application includes untrusted data in a new web page without proper validation.
A8 Insecure Deserialization
Occurs when attackers inject malicious code into serialized data.
A9 Using Components with Known Vulnerabilities
Occurs when attackers identify weak components or dependencies by scanning.
A10 Insufficient Logging and Monitoring
Scenarios where detection software either does not record the malicious events or ignores details.

Attack and testing tools

Burp Suite
Supports initial mapping and analysis of an application's attack surface.
OWASP ZAP Attack Proxy
Provides an automated scanner and tools that allow you to find security vulnerabilities manually.
N-Stalker Web App Security Scanner
Checks for vulnerabilities such as SQL injection, XSS, and other known attacks.
Fortify WebInspect
An automated dynamic testing solution to identify and prioritize security vulnerabilities.

SQL injection

Server-Side Technology
Allows developers to create dynamic, data-driven websites and web apps with ease. Easily exploited by hackers.
SQL Injection
Unsanitized input vulnerabilities that allow SQL commands to pass through a web application, to gain unauthorized access or retrieve information.
In-Band SQL Injection
Attackers use the same communication channel to perform the attack and retrieve the results.
Out-of-Band SQL Injection
Uses different communication channels to perform the attack.
Error-Based SQL Injection
Forces the database to perform operations in which the result will be an error.
Union SQL Injection
Joins a forged query to the original query.
Blind/Inferential SQL Injection
No error message and time-intensive.
SQLmap
Automates the process of detecting and exploiting SQL injection flaws.

Module 8: Wireless Attack

Wireless Network: Allows devices to access the network anywhere within the AP range.

Wireless encryption

802.11i
Security mechanisms.
WEP
Encryption algorithm.
EAP
Supports multiple authentication methods.
LEAP
Proprietary version of EAP.
WPA
Advanced wireless encryption protocol.
TKIP
Used by WPA as a replacement for WEP.
WPA2 Encryption
Upgraded version of WPA and includes mandatory support for counter mode.
  • WPA2-Personal: uses a setup password to protect unauthorized network access.
  • WPA2-Enterprise: includes EAP or RADIUS for centralized client authentication.
WPA3 Encryption
Advanced implementation of WPA2.
  • WPA3-Personal: password-based authentication using SAE.
  • WPA3-Enterprise: protects sensitive data using many cryptographic algorithms.

Wireless attack tools

Aircrack-ng Suite
Network software suite that consists of a detector, packet sniffer, WEP and WPA/WPA2-PSK cracker, and analysis tool.
AirMagnet WiFi Analyzer Pro
Performs reliable WiFi analysis.

Wireless network attacks

1. Rogue AP Attack
Hijacks the connection of legitimate network users.
2. Unauthorized Association
Attacks infect the victim machine and an active soft AP, thus allowing them to establish an authorized connection.
3. Ad-Hoc Connection
Compromises the client in ad hoc mode.
4. Honeypot AP Attack
An unauthorized AP set up to impersonate a legitimate network.
5. AP MAC Spoofing
Spoofs the MAC address and connects to the AP.
6. Key Reinstallation Attack (KRACK)
Uses the 4-way handshake process to join the network.
7. Jamming Signal Attack
An attacker stakes out the area from a nearby location with a high-gain amplifier.

Bluetooth

Bluetooth
Short-range wireless communication that replaces cables. Allows devices to share data over short distances. Has discoverable modes and pairing modes.
Bluetooth Hacking
Exploitation of Bluetooth stack implementation vulnerabilities.
Bluesmacking
Overflow.
Bluejacking
Sending unsolicited messages.
Bluesnarfing
Theft of information.
Bluesniffing
Wardriving.
Bluebugging
Remotely accessing a device.
BluetoothView
Bluetooth attack tool that monitors active Bluetooth devices.

Module 9: Mobile Attacks

Mobile Attack Vectors
  • Malware
  • Data Tampering
  • Data Exfiltration
  • Data Loss
Mobile Spam
Unsolicited text/email messages with a significant amount of bandwidth wasted.
SMS Phishing Attack (SMiShing)
The act of trying to acquire personal or financial information by sending SMS.
Open Connections
Allows attackers to eavesdrop and intercept data transmission.
Agent Smith Attack
Persuading the victim to install a malicious app by replacing legitimate apps.
SIMjacker
Vulnerability associated with the SIM card S@T browser. Performing DoS attacks.

Hacking tools and management

Metasploit (Android)
Creates binary payloads that are sent to target Android devices.
zANTI (Android)
Android app that allows you to spoof MAC addresses, create malicious Wi-Fi, or hijack sessions.
Elcomsoft Phone Breaker (iOS)
Logical and over-the-air acquisition of iOS devices, background encryption break, and obtain.
Mobile Device Management (MDM)
Provides a platform for over-the-air or wired distribution of applications.
Bring-Your-Own-Device (BYOD)
Allows employees to bring personal devices to workplaces.

Module 10: IoT and OT Attacks

Internet of Things: Network of devices having IP addresses and capability to sense, collect, and send data.

IoT architecture

Application Layer
Delivery of various applications to different users in IoT.
Middleware Layer
Device management and information management.
Internet Layer
Connection between endpoints.
Access Gateway Layer
Protocol translation and messaging.
Edge Technology Layer
Sensors, devices, machines, and intelligent edge nodes.

IoT attacks and tools

DDoS Attack
Exploiting vulnerabilities through an army of botnets.
Exploit HVAC
HVAC systems have many security vulnerabilities.
BlueBorne Attack
Performed over Bluetooth to gain access.
Jamming Attack
Jams communication between IoT devices.
SDR-Based Attack
Examines communication and sends spam content.
Fault-Injection Attack
Injects a faulty or malicious program into the system.
SeaCat.io
IoT security tool: security-first SaaS technology.

Operational Technology (OT)

Operational Technology
Detects or causes changes in industrial operations.
Purdue Model
Used to describe internal connections and dependencies.
HMI-based Attack
Controls the critical infrastructure and causes physical damage to the SCADA device.
Side Channel Attack
Physical implementation to obtain critical information.
  • Timing Analysis: finish one complete.
  • Power Analysis: power consumption.
Hacking Programmable Logic Controller
Controlling the physical process of critical infrastructure.

Module 11: Cloud Computing

Cloud Computing: On-demand delivery of IT capabilities.

Service models

Infrastructure as a Service
Virtual machines and other abstracted hardware.
Platform as a Service
Development tools, config management, and deployment platforms.
Software as a Service
Software delivered to subscribers on-demand over the internet.
Identity as a Service
IAM services and intelligence collection.
Container as a Service
Virtual container engines.
Security as a Service
Penetration testing, authentication, intrusion detection, etc.
Function as a Service
Application functionalities.

Deployment models

Private Cloud
Operated for a single organization only.
Community Cloud
Shared between several organizations from a specific community.
Hybrid Cloud
Combination of two or more clouds.
Multi-Cloud
Combines workloads across multiple cloud vectors.

NIST cloud architecture

Cloud Consumer
Uses cloud services.
Cloud Provider
Provides cloud services.
Cloud Carrier
Provides connectivity.
Cloud Auditor
Independent assessment.
Cloud Broker
Manages cloud services.

Storage, containers, and virtualization

Cloud Storage
Medium used to store digital data in logical pools.
  • Front-end: accessed by the end user.
  • Middleware: several functions.
  • Back-end: where the hardware is implemented.
Container
Application or software including all its dependencies. CaaS consists of containers managed through orchestrators.
Virtualization
Ability to run multiple OS on a single physical system.
Containers
Share the OS kernel and binaries and libraries.
Docker
Open-source tech used for developing dependencies in containers. Provides PaaS through OS-level virtualization.
Microservices
Break down monolithic applications, with each microservice packaged into a Docker container.
Container Orchestration
Automated process of managing the lifecycle of software containers.
Kubernetes
Open-source, portable, and extensible orchestration platform developed by Google. Framework for containers.

Cloud attacks

Side-Channel Attack
Runs a virtual machine on the same physical host as the victim.
Wrapping Attack
During translation of SOAP messages.
Man-in-the-Cloud
Tricks victims into installing malicious code.
Cloud Hopper Attack
Triggered at the managed service provider and initiates spear-phishing.
Cloud Cryptojacking
Stealthily mines digital currency.
Cloudborne Attack
Vulnerability in a bare-metal cloud server that enables attackers to implant a malicious backdoor.
Lazys3
Ruby script tool used to brute-force AWS S3 buckets.
Nimbostratus
Tool used for fingerprinting and exploiting Amazon cloud infrastructure.

Module 12: Penetration Test

Penetration Testing
Test an organization's ability to protect its infrastructure, such as networks, apps, or systems.
Security Audit
Checks whether the org follows security policies and procedures.
Vulnerability Assessment
Discovering vulnerabilities.
Penetration Testing (vs. the two above)
Determines whether the vulnerabilities can be exploited by an attacker.
Red-Team-Based Penetration Testing
Goal-based assessment where pen testers must mimic the behavior of a real attacker.
Compliance-Oriented Penetration Testing
Driven by compliance requirements.

Risk from penetration testing

Technical Risk
Directly arises with target in the production environment.
Organizational Risk
Side effect of penetration testing.
Legal Risk
Legal obligations.
